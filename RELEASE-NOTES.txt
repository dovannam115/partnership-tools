v2.1.0 (12/11/2026)
- The app is now called Upselling Tools, with a new chart icon. The Desktop and Start menu shortcut is renamed on the next start: the old Partnership Tools shortcut goes away and an Upselling Tools one takes its place.
- Search Windows for 'Upselling' to open it. A taskbar pin made with the old name has to be pinned again.

v2.0.0 (12/11/2026)
- Invoice requests (XHĐ): release with the changes of 1.1.0 and 1.1.1 (bulk slips for unit 13, Print + Accounting folders in the zip, new motorbike GCNBH layout).

v1.1.1 (12/11/2026)
- Invoice requests (XHĐ): fees are read from the new motorbike GCNBH layout (Phí bảo hiểm: ..., TỔNG PHÍ BH: ...). Before, these slips asked to fill the fee lines by hand.

v1.1.0 (12/11/2026)
- Invoice requests (XHĐ): bulk slips for khách lẻ work again for policies of unit 13 (26/45/13/...). Before, every PIAS row of unit 13 was left out, so only the request slips came out.
- Invoice requests (XHĐ): the zip now has two folders. Print keeps the layout as before. Accounting has one folder per customer request (its own PTT, the GCNBH and, after the tax lookup, the Tax ID printout) and one folder per bulk slip (PTT + list).
- Invoice requests (XHĐ): the PIAS warning now names the unit codes left out.

v1.0.9 (05/11/2026)
- Rabbit Care: two upload boxes, one for the policy export (needed) and one for the SĐBS export (optional). Without a SĐBS file the Điều chỉnh line is 0. A warning shows when a file sits in the wrong box.

v1.0.8 (05/11/2026)
- Rabbit Care: the Danh sách sheet is split into Cấp mới and Điều chỉnh (SĐBS), each with its own STT and subtotal, then the grand total. BBĐS takes the two subtotals.

v1.0.7 (05/11/2026)
